# AI-Generated Text Detection Guide

## Overview
`src/core/ai_detector.py` estimates how likely a piece of text is to be
AI-generated. It does this by combining one machine-learning signal
(a transformer classifier) with several lightweight statistical signals
computed directly from the text, plus a separate set of stylometric
features used for authorship/consistency analysis.

This document explains each metric, how the pipeline combines them into a
confidence tier, and how to interpret or tune the thresholds.

## The Five Metrics

### 1. Transformer AI Probability (`detect_ai_probability`)
- **What it measures:** The likelihood (0.0–1.0) that the text was
  generated by an AI model, as judged by a fine-tuned classifier.
- **How it's computed:** The text is tokenized and passed through the
  `roberta-base-openai-detector` model (configurable via the
  `AI_DETECTION_MODEL` environment variable). The softmax probability of
  the "AI/Fake" class is returned. If the model can't be loaded, the
  function falls back to `0.0`.
- **Typical range:** 0.0–1.0. This is the primary score used for the
  confidence tier (see below).

### 2. Perplexity Score (`calculate_text_perplexity`)
- **What it measures:** How "predictable" the text is to a language model.
  Lower perplexity means the text is easier to predict word-by-word, which
  is characteristic of AI-generated writing. Human writing tends to be
  less predictable (higher perplexity).
- **How it's computed:** Cross-entropy loss is computed by running the
  same transformer model over the text with its own tokens as labels,
  then perplexity = `exp(loss)`. Values are clamped to `[0, 10000]` to
  avoid overflow.
- **Typical range:** Most human text falls roughly between 20 and 200.
  Values are normalized to 0–1 via `normalize_perplexity()` using
  `raw / (raw + scale_factor)` (default `scale_factor = 100.0`), and can
  be bucketed with `categorize_perplexity_score()`:
  - `< 30` → "Highly Predictable"
  - `30–69` → "Moderate"
  - `>= 70` → "Unpredictable"

### 3. Burstiness (`_calculate_burstiness`)
- **What it measures:** Variation in sentence length. Human writing tends
  to mix short and long sentences (high burstiness); AI writing tends to
  be more uniform (low burstiness).
- **How it's computed:** Coefficient of variation (`std / mean`) of
  word-counts-per-sentence, capped at `1.0`.
- **Typical range:** 0.0 (uniform) to 1.0 (highly varied). Human text
  commonly falls between 0.3 and 0.8.

### 4. N-gram Repetitiveness (`_calculate_ngram_repetitiveness`)
- **What it measures:** How often the same short word sequences (default:
  3-word n-grams) repeat. AI text tends to reuse certain phrasing patterns
  more than human text.
- **How it's computed:** `1 - (unique n-grams / total n-grams)` over the
  full text.
- **Typical range:** 0.0 (no repeats) to 1.0 (highly repetitive).

### 5. Stylometric Features (`extract_stylometric_features`)
Used mainly for authorship-consistency checks rather than the AI-probability
score itself, but useful supporting context:
- **Type-Token Ratio (TTR):** unique words / total words — vocabulary
  diversity. Range `(0, 1]`; higher usually means more human-like variety.
- **Average Word Length:** mean character count per word.
- **Average Sentence Length:** mean word count per sentence.
- **Sentence Length Variance:** statistical variance of sentence lengths
  (a second, unnormalized view of burstiness).
- **Yule's K:** a length-independent vocabulary-richness measure. Lower
  values indicate richer vocabulary. Typical human text: roughly 100–200.

## Confidence Tiers and Thresholds
The overall classification is driven by the transformer AI probability
score (metric 1), using two constants defined at the top of
`ai_detector.py`:

```python
AI_HIGH_THRESHOLD = 0.75
AI_MEDIUM_THRESHOLD = 0.40
```

| `ai_probability` range | Tier / Label |
|---|---|
| `>= 0.75` | High (`"High Probability"`) |
| `0.40 – 0.749...` | Moderate (`"Moderate Probability"`) |
| `< 0.40` | Low (`"Low Probability"`) |

`categorize_ai_probability(score)` maps a raw score to the UI label above.
`detect_ai_generated_text(text)` maps the same score to the internal tier
key (`"high"`, `"medium"`, `"low"`), used as `confidence_tier` /
`classification_tier`.

To retune sensitivity, adjust `AI_HIGH_THRESHOLD` / `AI_MEDIUM_THRESHOLD` —
both categorization functions read from the same constants, so they stay
in sync.

## How `detect_ai_generated_text()` Combines the Signals
For a given text, the function:
1. Computes the transformer probability (metric 1) — this alone decides
   the confidence tier.
2. Computes perplexity (metric 2), burstiness (metric 3), and n-gram
   repetitiveness (metric 4) as **supporting signals**, returned alongside
   the tier so callers/UI can show corroborating evidence.
3. Returns a single dictionary:

```python
{
    "ai_probability": 0.82,
    "confidence_tier": "high",
    "classification_tier": "high",  # kept for API compatibility
    "perplexity_score": 18.4,
    "burstiness_score": 0.12,
    "ngram_repetitiveness": 0.35,
}
```

Note that only `ai_probability` decides the tier — perplexity, burstiness,
and n-gram repetitiveness are not currently blended into the score itself;
they are provided as additional context for the caller.

## Decision Flow
            text
             │
             ▼
  detect_ai_probability(text)
             │
             ▼
    ai_probability (0.0–1.0)
             │
┌─────────────┼──────────────┐
│ │ │
< 0.40 0.40–0.749 >= 0.75
│ │ │
▼ ▼ ▼
"Low" "Moderate" "High"
Probability Probability Probability


Perplexity, burstiness, and n-gram repetitiveness are computed in parallel
and attached to the result for display, but do not change which branch is
taken above.
