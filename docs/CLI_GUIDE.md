# 🖥️ CLI Guide

This guide explains how to use the headless command-line interface (`cli.py`) for automating plagiarism detection and FAISS index synchronization.

---

# Overview

The CLI provides two commands:

- `scan` – Scan a folder of documents and generate a plagiarism report.
- `sync-index` – Verify and repair synchronization between the FAISS index and the SQLite database.

---

# Basic Syntax

```bash
python cli.py <command> [options]
```

---

# Commands

## scan

Scans a folder containing documents and outputs a JSON plagiarism report.

### Syntax

```bash
python cli.py scan <folder> [--threshold <value>]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `folder` | Path to the folder containing documents. |

### Options

| Option | Default | Description |
|---------|---------|-------------|
| `--threshold` | `0.59` | Similarity threshold used to flag plagiarism. Must be between `0.0` and `1.0`. |

---

## sync-index

Verifies that the FAISS index and SQLite database are synchronized and repairs inconsistencies if necessary.

### Syntax

```bash
python cli.py sync-index
```

---

# Examples

## Scan a folder

```bash
python cli.py scan ./assignments
```

---

## Scan with a custom threshold

```bash
python cli.py scan ./assignments --threshold 0.75
```

---

## Synchronize the FAISS index

```bash
python cli.py sync-index
```

# Exit Codes

# Exit Codes

| Exit Code | Meaning |
|-----------|---------|
| `0` | Command completed successfully. |
| `1` | Runtime error (invalid folder, processing failure, invalid threshold, synchronization failure, etc.). |
| `2` | Invalid command-line syntax or unsupported command (generated by `argparse`). |

---

# Error Conditions

The CLI returns an error when:

- The specified folder does not exist.
- The provided path is not a directory.
- The threshold is outside the range `0.0–1.0`.
- Document parsing fails.
- The plagiarism detection pipeline encounters an error.
- FAISS synchronization fails.

Warnings are printed for:

- Empty extracted documents.
- Documents that cannot be parsed.

---

# Supported File Types

The `scan` command processes:

- PDF (`.pdf`)
- Microsoft Word (`.doc`, `.docx`)
- Plain Text (`.txt`)

Hidden files are ignored automatically.

---

# Automation

The CLI is designed for automation and scripting.

Example:

```bash
python cli.py scan ./assignments > report.json
```

Store logs separately:

```bash
python cli.py scan ./assignments > report.json 2> errors.log
```

Use the exit code in shell scripts:

```bash
python cli.py scan ./assignments

if [ $? -eq 0 ]; then
    echo "Scan completed successfully."
else
    echo "Scan failed."
fi
```

# Notes

- Output is written to standard output (stdout) as formatted JSON.
- Errors and warnings are written to standard error (stderr).
- Reports can be redirected to a file using standard shell redirection.
