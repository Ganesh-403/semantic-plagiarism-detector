# Glossary of Terms

This document defines domain-specific terminology used across the Semantic Plagiarism Detection System codebase to assist new contributors.

---

### FAISS (Facebook AI Similarity Search)

A library developed by Meta's AI research group for efficient similarity search and clustering of dense vectors. In this project, FAISS is used to perform fast nearest-neighbor lookups of document embeddings to identify potential plagiarism.

### Embedding

A dense, high-dimensional numerical vector representation of text (words, sentences, or documents) generated by a neural network. Embeddings capture the semantic meaning of the text, enabling mathematical comparisons of semantic similarity rather than just keyword matching.

### Chunk

A contiguous block or segment of text extracted from a larger document during preprocessing. Document texts are chunked to allow fine-grained semantic analysis, citation extraction, and block-by-block similarity comparison.

### Cosine Similarity

A mathematical metric used to measure how similar two vectors are. It computes the cosine of the angle between two multi-dimensional vectors in a inner product space. A value of `1.0` indicates identical directions (high semantic similarity), while `0.0` or negative values indicate independence.

### SSRF (Server-Side Request Forgery)

A security vulnerability that occurs when a web application fetches a remote resource without validating the user-supplied URL. An attacker can abuse this to force the server to make requests to internal resources, loopback interfaces, or third-party servers.

### TTR (Text-to-Template Ratio)

A text extraction heuristic used in Web content mining. TTR measures the ratio of content text to template/boilerplate HTML tags to filter out headers, footers, and sidebars, extracting only the primary body article.

### Perplexity

A metric used in natural language processing (NLP) to evaluate probability models. It measures how well a probability distribution or language model predicts a sample. Lower perplexity indicates the text is highly structured and predictable (often indicating AI-generated content).

### HMAC (Hash-based Message Authentication Code)

A cryptographic construction that uses a hash function (such as SHA-256) combined with a secret cryptographic key. It is used to simultaneously verify both the data integrity and the authenticity of a message or request payload.

### WAL (Write-Ahead Logging)

A database recovery technique where changes are recorded in a dedicated log file before they are written to the database database. This ensures transaction durability (ACID compliance) and protects against database corruption during power losses or system crashes.

### OCR (Optical Character Recognition)

The mechanical or electronic conversion of images containing printed, handwritten, or typed text into machine-encoded, editable text. Used in this project to extract text from scanned PDF documents and image files.

### Corpus

A structured, representative collection of documents or text samples compiled for linguistic analysis, model training, or plagiarism cross-reference checks.

### Jaccard Similarity

A statistic used for gauging the similarity and diversity of sample sets. It is calculated by dividing the size of the intersection of two sets by the size of their union, representing word overlap similarity.

### Needleman-Wunsch

A classic dynamic programming algorithm used for global sequence alignment. In the context of plagiarism detection, it is used to perform precise word-by-word alignment of similar passages to highlight exactly what was copied, inserted, or modified.

### HSTS (HTTP Strict Transport Security)

A web security policy header that forces browsers to connect to the server exclusively over secure HTTPS connections, preventing man-in-the-middle attacks and SSL stripping.

### Telemetry

The automated process of collecting, measuring, and transmitting system performance, usage metrics, error logs, and system diagnostics to monitor application health and performance in production environments.
